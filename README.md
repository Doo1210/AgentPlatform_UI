## 已实现

- 开通演示最新规则：高级功能四项默认仅运行时开通，工业引擎默认仅本体开通；介绍页点击“立即开通”后导航立即出现，刷新恢复默认，无需申请或审批。

- 总览：紧凑呈现专家与工作流数量及分时段使用次数、技能/MCP/插件/知识库概况、四张工业引擎卡片；智能体运行时按组织开通
- 主侧栏：总览、资产广场、智能应用（专家/工作流）、能力与资源（模型管理、知识中心、资源库、事件中心）、高级功能及工业引擎；后两组仅显示当前组织已开通的入口，工业引擎菜单进入对应平台专属导航
- 除事件中心外，主平台模块统一采用右侧顶部功能 Tab，移除并列副导航及重复的顶部模块标题；右侧内容区使用 `padding: 20px 20px 16px`。主导航只由用户手动展开或收起，并记住手动偏好，切换模块不改变宽度
- 除总览外，所有右侧页面统一使用白色圆角背景容器，圆角 16px、内边距 `20px 20px 16px`，外部留出页面边距；覆盖资源页面、功能模块、介绍页、工业引擎及管理页面
- 列表和卡片页仅数据区域独立滚动，顶部 Tab、筛选与操作栏保持可见；工业引擎表头和分页保留在原位。资产广场不展示精选横幅，直接展示可独立滚动的资源卡片，低代码的数据与配置区独立滚动，介绍和表单页保留正常阅读滚动
- 高级功能与工业引擎采用主平台同一套右侧样式：紧凑操作栏、搜索筛选靠左、主操作靠右、无外围框表格、统一浅色卡片；介绍页标题栏放入白色内容容器，取消独立固定顶栏和深色展示区，开通与跳转流程保持现状
- 总览右上方“返回旧版”切换到源码参考的旧版侧栏（180px、二级导航、底部管理浮出菜单），右侧仅显示页面名称大字；点击旧版 Logo 返回新版总览，保留组织、角色和开通状态。依据 wanwu-web 的 layout/index.vue、el-menu.js 与中文语言文件，不连接生产系统。
- 工业平台：已开通卡片主体直达专属侧栏，“查看介绍”进入介绍页；未开通卡片进入介绍页；本体平台保留原有专业页面
- 事件中心无 Tab，使用搜索框旁的类型下拉框切换事件接入、事件任务和执行记录；专家、工作流、模型管理、知识中心、资源库及高级功能通过顶部一级 Tab 切换，并记住本次会话中的选择；智能应用洞察在内容面板内用二级分段 Tab 区分评测任务与数据集等视图，资源库提供全部/我的收藏/我的创建筛选。低代码 UI 包含应用管理、资源管理、调用工具管理、数据看板，应用管理保留创建、预览和多工作流绑定，并提供范围筛选与搜索
- 资产广场在页面内切换专家、工作流、解决方案、工具和模型
- 底部用户区显示姓名、角色和当前组织；组织切换与个人菜单使用两个独立按钮，并保留角色预览及平台运营/管理中心演示开关

平台开通状态、工作指标及列表内容目前为**原型示例数据**，页面内的开通操作只改变当前会话状态；尚未接入实际审批、权限和工业平台服务。初始组织中本体平台设为已开通，用于体验专属侧栏；其他平台设为未开通。
